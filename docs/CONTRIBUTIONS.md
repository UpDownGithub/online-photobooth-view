# 개발 기여와 AI 활용

## 담당 범위

| 참여자 | 기여 |
| --- | --- |
| 본인(UpDownGithub) | 서비스 전반, 사용자 화면, 다자간 상호작용, 촬영 흐름과 이미지 처리 |
| 동료 1명 | 관리자 화면 개발 |

## 개발 과정

- 참가자가 방에 들어와 함께 촬영하고 결과를 받는 전체 흐름을 구현했습니다.
- 브라우저 카메라와 영상 화면을 다루고, 화면 상태 변화에 맞춰 사용자 인터페이스를 갱신했습니다.
- 사진 배치와 장식 표현을 연결하고 결과 이미지를 다루는 경험을 쌓았습니다.
- 서로 다른 기기에서 발생하는 동작 차이를 확인하며 화면과 영상 관련 문제를 개선했습니다.

설계, 코드 작성과 디버깅에 AI 도구를 활용했습니다.

이 저장소는 연구실 지원을 위한 프로젝트 소개 자료입니다. 선별한 실제 코드와 공개용 발췌 예시를 함께 소개합니다. 서비스 운영 코드와 내부 운영 자료는 공개 범위에 포함하지 않습니다.
